# Dastgah Scales

Measured tunings of Iranian masters: the absolute pitch of every note, the
intervals of each dastgah's scale, and how performances move through them.

**Site:** https://zamirsworld.github.io/dastgah-scales/

Each recording is analysed many times by independent pitch estimators, and only
what they agree on is published, with its support and uncertainty. No
recordings are hosted here: the site plays a synthesized version of each
measured tuning and links to the original at its publisher.

This repository holds only the generated static site. It is published by the
analysis pipeline (pipeline 0.9.1); please don't edit it by hand.
